## Create App Integratioin Workflow
### The flow of creating an integration:
- Create a plan by research online what is the best way to integration. See if we can integrate trigger or only actions, In the the plan mention all triggers and integration.
- Write the full test of the integration
- Register the integration in the includes/config/integrations.php file
- Start writing the integration
- Run the specific test
- Wrtie the frontend guide if need any in the docs/frontend folder in .md format
- Write a user setup guide in the docs/integrations/app
